해부학 Atlas와 실제 MRI

해부학 Atlas에서 구조와 위치를 익힌 뒤 실제 MRI로 넘어갑니다. 실제 MRI 모드에서는 StudyForrest 참여자 4명의 3T T1/T2 촬영 영상을 제공합니다. 3명은 학습, 1명은 별도 전이 연습에 사용합니다. 개인 분할은 같은 사람의 FreeSurfer 자동 분할을 참고용으로 표시하며 임상 정답으로 채점하지 않습니다. 한국어 설명은 자료와 대조한 교육 콘텐츠이며 전문의 경계 검수와 교육 효과 검증은 수행하지 않았습니다.

해부학 Atlas에는 42종 80개 영역을 제공합니다. 기존 CIT168 구조에 피질·변연계·뇌간 구획을 추가했습니다. 해부학 Atlas의 각 마스크에서 3D를 생성했습니다. 개인 모드의 핵심 3D는 해당 개인의 자동 분할에서 제작하여 T1 공간에 표시합니다. 해부학 Atlas는 원래 표준 공간을 유지합니다. 개인 자동 분할은 전문의가 검수한 정답이 아닙니다. 미세 핵과 기능적 피질 영역은 직접 시각화와 위치 추정을 구분합니다.

담장·중격 영역은 맞춤 ICBM2009b symmetric MRI로 전환합니다. 외측중격핵 단독 분할은 제공하지 않으며 중격 영역 참고로만 표시합니다. 봉선핵은 등쪽·정중 봉선핵을 포함합니다.

확장 atlas 출처·이용 조건·정합 한계

기존 CIT168 구조는 가장 높은 확률의 라벨이 64/255 이상인 복셀만 표시합니다. 다른 atlas의 구획·변환 기준은 확장 출처 안내에 기록했습니다. 이 표시 기준은 생물학적으로 확정된 경계를 뜻하지 않습니다. 같은 라벨에서 3D 표면과 MRI 오버레이를 만들었습니다.
