# 구조 위치의 근거와 검증 범위

2026-09-07. 이 앱의 개인 MRI는 동일인의 자동 분할을 이용하는 관찰 훈련 파일럿이다. 임상 전문가가 경계를 확정한 정답 자료는 아니다.

## 발견한 오류와 수정

개인 MRI의 탐색에서 구조·좌우를 바꿀 때 제목과 참고 마스크만 바뀌고 십자선은 이전 위치에 남았다. 초기 위치 역시 기본 학습 대상인 해마의 위치가 아니었다. 참고 경계를 연 뒤에만 위치 이동 버튼이 나타나서, 제목을 십자선의 해부학적 이름으로 오인할 수 있었다. 기존의 ‘이동 버튼 → 저장 앵커 일치’ 검사는 이 일상적인 선택 경로의 오류를 잡지 못했다.

탐색에서는 구조·좌우·사례 변경 시 해당 개인의 선택 분할 내부 지점으로 이동한다. 이동 버튼은 경계 표시와 분리했다. 십자선을 직접 옮기면 현재 복셀의 자동 라벨과 선택 영역 안/밖을 갱신한다. 안내·추적·전이에서는 목표 이름을 현재 위치 이름으로 표시하지 않고, 위치 도움을 사용했는지 기록한다. 전이의 첫 응답 전에는 위치 도움과 라벨 공개를 잠근다.

이 수정은 탐색 동작의 오류를 해결한다. 자동 분할의 모든 경계가 해부학적으로 옳다고 증명하지는 않는다.

## 개인 MRI: FreeSurfer, AAL normalization 없음

1. StudyForrest의 개인 T1과 그 사람의 FreeSurfer 5.3 `aparc+aseg.mgz`를 사용한다. 예를 들어 해마는 원천 ID 17/53, 시상은 10/49이다. 전체 대응표와 개별 앵커는 각 사례의 `case.json`에 있다.
2. FreeSurfer 입력 `rawavg.mgz`와 배포 T1의 복셀 순서를 canonical 방향으로 맞춰 같은 촬영인지 검사한다. 파일 변환에 따른 헤더 차이를 `T1_canonical.affine × inverse(rawavg_canonical.affine)`로 보정한다. 이 행렬을 원래 분할 affine에 적용한다. 이는 표준공간으로의 normalization이나 사람 간 비선형 정합이 아니다.
3. 해당 원천 ID의 실제 복셀을 선택하고 경계까지의 거리 변환이 최대인 내부 복셀을 이동 지점으로 삼는다. 임의의 MNI 좌표나 LLM 추정 좌표를 사용하지 않는다. 큰 구조나 여러 구획의 합집합에서 이 점은 전체 구조를 대표하는 유일한 해부학적 중심이 아니다.
4. T1 원본 강도·촬영 그리드를 유지한다. T2만 동일인의 T1에 강체 정합한 파생본으로 표시하고, 원본도 보존한다.

FreeSurfer 분할 결과를 배포받아 사용한 것이며, 앱이 FreeSurfer 전체 파이프라인을 실행한 것은 아니다. 그 파이프라인 내부의 atlas 사용과 이 앱에서 AAL을 개인에게 정합하는 것은 구별해야 한다.

## 참고 Atlas: AAL3를 이미 사용하는 별도 표준공간

해마·편도체·뇌섬엽·여러 피질 영역·시상 등에 CAT12 배포 AAL3를 사용한다. AAL3 전체를 모두 제공하는 것은 아니며, CIT168 등 다른 atlas의 구조도 함께 제공한다. 각 ROI의 `assets/roi-manifest.json`에는 원천 atlas와 라벨 ID가 명시돼 있다.

[AAL 공식 설명](https://www.gin.cnrs.fr/fr/outils/aal/)의 AAL3는 정규화된 단일 피험자 MRI에서 정의한 해부학적 구획이다. 사용 중인 [CAT12 배포본 설명](https://github.com/ChristianGaser/cat12/blob/main/templates_MNI152NLin2009cAsym/aal3.txt)은 Collins T1의 분할·정규화 파라미터로 AAL3를 MNI152NLin2009cAsym에 옮겼다고 명시한다. 이 변환은 배포본의 전처리이며, 이 앱이 개인 사례 4명을 normalization한 것이 아니다.

참고 화면은 같은 표준 좌표계의 CIT168 T1 평균 템플릿을 배경으로 사용한다. 원래 AAL을 수동 정의한 단일인의 MRI와 동일한 뇌는 아니므로, 좌표계가 맞아도 모든 국소 경계가 배경 신호와 정확히 일치한다는 보장은 없다. 개인 MRI의 FreeSurfer 구획과 AAL 구획도 같은 이름만으로 동일한 정의라고 볼 수 없다. 앱의 ‘AAL3에서 관련 영역 보기’는 별도 표준공간으로 전환하는 기능이다.

## 개인에게 AAL을 적용하려면

현재 미구현이다. 구현 시에는 다음 산출물이 필요하다.

- AAL 버전과 정확히 대응하는 표준 T1 템플릿을 고정하고, 개인 T1에서 그 템플릿으로 가는 정합을 추정한다. 전체 뇌 형태의 차이를 반영하는 비선형 정합과 전처리 품질을 검토한다.
- 역방향 변환을 사용해 atlas의 정수 라벨을 개인 T1 그리드로 가져온다. 라벨은 최근접 이웃 방식으로 재표본화하고 변환 방향·순서·기준 영상을 검증한다. 헤더를 바꾸거나 동일 그리드로 resample만 하는 것은 정합이 아니다.
- 원본을 보존하고 정합 템플릿, 변환 파일, checksum과 처리 이력을 기록한다.
- 좌우·뇌실·뇌량 등 전체 랜드마크와 해마·시상 등 국소 경계를 세 방향에서 검사한다. 기존 FreeSurfer는 비교 자료로 활용할 수 있지만 독립적인 임상 정답으로 간주하지 않는다. 검수 실패 영역은 위치 정답으로 활성화하지 않는다.

AAL을 도입했다는 사실만으로 개인별 위치 정확도가 확보되지는 않는다. 정합 결과의 해부학적 검수가 필요하다.

## 무엇을 검사하며, 무엇이 남아 있는가

소프트웨어 회귀 검사는 일반적인 구조 선택, 좌우 변경, 사례 변경, 수동 이동, 시퀀스 유지, 첫 응답 잠금과 출처 표시를 확인한다. 별도의 nibabel 검사는 브라우저가 보고한 점을 원천 FreeSurfer 복셀로 역변환하여 실제 원천 ID와 맞는지 확인한다. 이는 자료·좌표·UI 경로의 일관성 검사다.

독립적으로 만든 세 방향 MRI 그림도 확인한다. 그러나 전문의의 사례별 국소 경계 검수, 물리적 좌우 표지 확인, 교육 효과 검증은 완료하지 않았다. 이 파일럿을 임상적 정확도가 인증된 판독 교육 자료 또는 자동 채점기로 표현하지 않는다.
