# 개인 MRI 판독 훈련으로의 재설계

작성: 2026-09-06. 업데이트: 개인 4명 T1/T2 확보·정합·통합 및 관찰·추적·비교·전이 훈련 구현. 데이터/브라우저 검증 근거는 [VERIFICATION.md](VERIFICATION.md). 자동 분할의 전문 경계 검수는 미수행이며 임상 정답 채점은 활성화하지 않음.

## 목표와 기존 접근의 문제

목표는 정신과 전문의가 처음 보는 사람의 axial, coronal, sagittal 연속 단면에서 구조의 위치, 형태, 주변 관계를 판단하는 것이다. 구조가 해당 단면에 없거나 해당 시퀀스로 경계를 구분할 수 없는 경우도 판단해야 한다.

현재 구현은 집단 평균 atlas를 탐색하고 그 마스크를 찾는 데 적합하다. 개인의 정상 변이, 실제 영상의 신호와 경계, 시퀀스에 따른 차이를 배우는 기본 자료로는 부족하다. 현재 CIT168 배포본은 1 mm 격자·8-bit이며, 확대나 보간은 평균화로 사라진 개인 해부학 정보를 복원하지 못한다. 복셀 간격, 영상의 유효 공간 해상도, 화면 표시 해상도를 구별한다.

기존 3D 회전·투명도·구조 선택, MRI 단일/3면 보기, 화면 분할은 보존한다. 기본 학습 단위는 구조 이름에서 **개인 영상 사례와 판독 과제**로 바꾼다.

**3D 모델은 공간적 관계를 이해하는 보조 도구다. 학습·평가의 대상은 실제 MRI 판독이며, 3D 모델 자체의 판독 능력을 요구하지 않는다.** 3D를 개인 MRI와 정확히 정합하거나 같은 사람의 표면으로 재구성할 필요는 없다. 지나치게 정교한 표면과 세부 구조는 시각적 복잡성을 높여 학습을 저해할 수 있으므로, 이해에 필요한 형태·방향·인접 관계를 유지하면서 단순화한다. 모델의 정교함보다 설명의 명료함을 우선한다.

## 데이터 선택

첫 검증 대상으로 StudyForrest 개인별 3T T1w와 T2w 볼륨을 선정한다. 공식 촬영 설명상 T1 acquisition voxel size는 0.7 mm이며 재구성 matrix와 간격은 별도 정보이다. T2의 촬영 기하 조건은 T1과 대응한다. 같은 사람의 FreeSurfer 피질 재구성도 공개되어 있지만, 이를 사용하는 것은 데이터 선택이나 구현 완료의 조건이 아니다. 프로젝트의 7T fMRI와 3T 구조영상을 혼동하지 않는다.

- [공식 영상 종류·촬영 조건](https://studyforrest.org/data.html)
- [구조영상 저장소와 파일별 접근 설명](https://github.com/psychoinformatics-de/studyforrest-data-structural)
- [데이터 저장소 LICENSE: PDDL](https://github.com/psychoinformatics-de/studyforrest-data-structural/blob/master/LICENSE)
- [구조영상 데이터 DOI](https://doi.gin.g-node.org/10.12751/g-node.zdwr8e/)

공식 저장소는 등록 없는 접근을 안내한다. GitHub의 NIfTI/JSON 경로 중에는 실제 파일 대신 git-annex 포인터가 있으므로, 저장소의 파일 목록을 읽었다는 사실을 다운로드 완료로 간주하지 않는다. 첫 사례의 실제 파일을 확보한 후 헤더·강도 범위·방향·피복 범위·영상 품질을 확인해야 한다. 문헌상의 촬영값만으로 설치 파일의 해상도를 표시하지 않는다.

고급 심부 구조용 후속 후보는 [ATAG 7T 자료](https://www.nature.com/articles/sdata201450)이다. 전뇌 0.7 mm 영상과 표적 0.5 mm slab을 구별하고, 도입 전 실제 데이터 접근·이용 조건·대상 구조별 대비를 확인한다. 더 높은 자장이나 작은 복셀만으로 모든 핵이 식별된다고 가정하지 않는다.

교과서 사진은 어려운 경계와 명칭을 검증하는 보조 자료로 사용한다. 기본 뷰어는 임의 위치로 이동하고 세 방향을 연결할 수 있는 개인 3D 영상 볼륨을 사용한다. 사진 추출을 주 데이터 확보 경로로 삼지 않는다.

## MRI와 라벨의 정확성, 3D의 교육적 역할

1. 개인 T1을 사례의 기준 공간으로 삼는다. 원본은 그대로 보존하고 표시용 파생본·변환·체크섬을 기록한다. 저장 강도를 8-bit로 축소하지 않고 표시 단계에서 window/level을 적용한다.
2. 같은 사람의 T2 등은 촬영 기하 조건이 같아도 움직임을 확인하고 정합한다. 원본과 변환을 보존하고 반복 resampling을 피한다.
3. MRI 위에 표시하거나 채점에 사용하는 라벨은 해당 개인 영상에서 위치와 경계를 검수한다. 개인 segmentation이나 atlas 변환을 사용할 수 있지만 자동 생성만으로 검증된 정답이 되지는 않는다. 개인 피질 표면의 3D 재구성은 요구하지 않는다.
4. 기존 atlas 라벨을 개인 MRI 위에 표시할 때는 정합 결과와 국소 오차를 검토한다. MNI 라벨과 개인 MRI를 좌표 확인 없이 겹치지 않는다. 이 정확성 요구는 MRI의 라벨·정답에 적용되며, 이해를 돕는 별도 3D 모델의 정밀 정합을 뜻하지 않는다.
5. 기존 3D 모델은 ‘이해를 돕는 참고 모델’로 유지한다. MRI와의 연결은 구조 이름, 선택한 학습 주제, 주변 구조와의 관계 수준이면 충분하다. 개인별 형태·복셀·경계·커서의 일대일 대응은 구현 요구에서 제외한다.
6. 3D에서는 선택 구조와 필요한 주변 구조를 강조하고 나머지는 숨기거나 단순화한다. 단면 방향을 설명하는 평면도 개념적 보조 표시로 사용할 수 있다. 이를 현재 개인 MRI의 정확한 절단 위치나 정답 경계로 제시하지 않는다.
7. AI 생성 MRI나 생성형 선명화 영상을 정답 자료로 사용하지 않는다. MRI의 원본 상세 보존과 보조 3D 모델의 단순화는 각각의 목적에 맞게 적용한다.

## 구조마다 다른 관찰 목표

요청한 전체 목록은 유지하되 모든 항목을 같은 방식으로 채점하지 않는다. 아래 분류는 초기 교육 설계이며, 실제 사례·시퀀스별 검수가 우선한다.

| 대상 | 학습 목표 | 정답 처리 |
|---|---|---|
| 미상핵, 조가비핵, 시상, 해마, 뇌섬엽 등 | 연속 단면의 형태와 주변 경계로 위치 식별 | 사례별 검수된 영역과 랜드마크로 평가; 전체 조직학적 경계가 보인다는 뜻은 아님 |
| 편도체, 측좌핵, 시상하부, 담장 등 | 보이는 경계와 주변 구조로 추론하는 경계를 구별 | 불확실한 경계 표시; 애매한 한 복셀의 정오 판정 제외 |
| 흑질·청반 등 작은 핵 | 시퀀스와 대비에 따라 관찰 가능한 범위 판단 | 해당 대비가 확보된 사례에서만 직접 식별 과제 제공 |
| VTA, 봉선핵, NBM, PPTN, 외측중격핵 등 | 주변 랜드마크와 해부학적 위치 학습 | 검증되지 않은 atlas 위치를 직접 보이는 핵의 정답으로 제시하지 않음 |
| dlPFC, vmPFC, DMN, CSTC 등 | 구조적 랜드마크에 기능적 영역·회로를 연결 | 정의와 출처가 있는 참고 영역/회로 설명; T1에서 직접 보이는 경계로 채점하지 않음 |

[Neuromelanin-sensitive MRI와 정신과 연구](https://www.nature.com/articles/s41386-024-01934-y)는 SN·LC를 다루는 데 영상 대비의 선택이 필요함을 뒷받침한다. 특정 핵의 위치를 아는 것과 일반 T1에서 그 핵의 경계를 직접 식별하는 것을 구별한다.

## 판독 중심의 학습 흐름

- **탐색:** 개인 영상에서 원하는 한 방향을 크게 보거나 세 방향을 동시에 본다. 연속 스크롤·window/level·확대·T1/T2 전환을 제공한다. 3D는 분할 또는 전체 화면으로 선택한다.
- **안내 학습:** 먼저 라벨 없이 관찰하고 필요할 때 주변 랜드마크, 다른 방향, 단순화된 3D 설명, 최종 경계로 도움을 받는다. 3D는 선택적으로 이용하며, 모델을 판독하거나 세부 형상을 외워야 다음 단계로 넘어가는 과제를 만들지 않는다.
- **추적:** 한 구조가 나타나고 형태가 바뀌고 사라지는 구간을 연속 단면에서 따라간다. 한 장의 대표 위치만 암기하는 과제로 끝내지 않는다.
- **비교:** 같은 사람의 세 방향과 시퀀스를 연결하고, 다른 사람에서 형태와 위치가 달라지는 것을 비교한다.
- **평가:** 학습에 쓰지 않은 사람의 MRI에서 위치·주변 관계·단면 내 존재 여부를 판단한다. 사례를 분리하지 않은 랜덤 slice 퀴즈를 일반화 능력 평가라고 부르지 않는다.
- **피드백:** 답이 어긋난 이유를 주변 구조와 실제 영상으로 설명한다. 미검수 경계에서는 정답/오답 점수 대신 참고 피드백을 준다.

## 정답 데이터 계약

사례에는 촬영 출처, 개인/평균 구분, 시퀀스, 자장, acquisition voxel size, 파일 voxel size, 데이터형, affine, 전처리, 라이선스, checksum을 기록한다. 알려지지 않은 항목은 미상으로 남긴다.

라벨에는 사례 ID, 기준 공간, 원천, 생성 방식(자동 segmentation/atlas 변환/수동), 변환 이력, 시퀀스별 관찰 가능성, 경계 불확실성, 검수 상태, 검수 기록을 연결한다. `학습 참고용`과 `채점 가능`을 구별한다. 자동 atlas membership은 그 자체로 임상 정답이 아니다.

과제에는 목표 구조, 방향, 유효 단면 범위, 사용할 수 있는 시퀀스, 확인할 랜드마크, 채점 방식, 허용 영역, 출제 가능 상태를 기록한다. 해당 단면에 없는 구조와 현재 영상에서 식별 불가능한 구조를 구분한다. LLM 설명은 출제 데이터와 연결하고, 이미지 속 정답을 임의 생성하지 않는다.

## 구현 순서와 완료 기준

### 1. 개인 영상의 품질부터 확인

한 사람의 T1/T2 원본을 확보하고 별도 사례 뷰어에서 라벨 없이 표시한다. 다운로드 실체·checksum·NIfTI 헤더·좌우·world 좌표·강도·세 방향을 확인한다. 원본 상세를 유지한 채 단일 뷰를 확대할 수 있어야 한다. 촬영 해상도와 화면 확대를 혼동시키지 않는다. 이 단계의 구현·데이터 검증·세 방향 시각 QC를 완료했다. 확인 범위와 제한은 VERIFICATION.md에 기록한다.

### 2. MRI의 랜드마크와 정답 검수

개인 MRI에서 랜드마크와 라벨의 국소 경계를 확인한다. 초기 범위는 해마, 편도체, 미상핵, 조가비핵, 담창구 전체, 시상, 뇌섬엽, 대상회와 뇌실·뇌량·내포 랜드마크다. 모든 항목이 첫 단계부터 채점 가능하다고 가정하지 않는다. 라벨 정합 오류와 관찰 불확실성을 기록한 뒤 검수된 과제만 활성화한다. 기존 3D 모델은 해당 구조의 공간 관계를 설명하는 데 재사용하며, 개인별 3D 생성·정밀 정합 때문에 MRI 학습 구현을 지연시키지 않는다.

### 3. 사례 간 전이 훈련

3–5명의 초기 사례로 안내·추적·비교 흐름을 검증하고 별도 개인을 평가용으로 남긴다. 축별 점수 외에 구조별 오류, 도움 사용, 다른 사람에서의 수행을 기록한다. 표본 수가 작은 파일럿을 교육 효과 검증으로 표현하지 않는다.

### 4. 전체 요청 구조로 확장

나머지 피질·변연계·뇌간 영역과 회로를 연결한다. 작은 핵은 적절한 시퀀스·검증 자료를 확보하면서 추가한다. 직접 보이지 않는 구조도 참고 atlas에서 탐색할 수 있게 유지한다.

완료 판단은 표시 가능한 구조 수가 아니라 **처음 보는 개인 MRI에서, 라벨을 가린 채, 단면을 이동하며 구조를 설명할 수 있는 훈련 경험**으로 한다. 현재 구현에서 재사용할 부분은 뷰어·분할·상호작용이며, 교체할 핵심은 기본 영상 데이터, 사례 모델, 라벨 검수 상태, 출제·채점 논리다.

3D의 완료 기준은 구조 간 관계를 쉽게 이해하도록 돕고 MRI 학습을 방해하지 않는 것이다. 개인 MRI와의 정밀 일치, 표면의 사실성, 모델 세부 묘사량은 완료 기준으로 삼지 않는다.


## 구현 반영 (2026-09-06)

위 요구사항은 유지한다. 현재 결과는 개인 MRI의 라벨 없는 관찰·서술 훈련 파일럿이다.

- StudyForrest 4명(학습 3명/전이 1명)의 실제 원본 T1/T2, 원본 해시·헤더·강도·affine, 정합 T2와 변환을 확보했다.
- 기존 분할/3D를 보존하고 기본 작업을 개인 사례로 옮겼다. 개인 MRI와 3D 사이의 거짓 복셀 대응을 제거했다.
- 26개 주제 × 4명 = 104개 관찰 과제 계약. 처음 보는 영상에서 색 없이 단면을 움직이고 위치·주변 관계·부재 판단·관찰 불확실성을 서술한다.
- 자동 개인 분할의 184개 영역 앵커·양측·공간과 세 방향 그림을 검사했다. 전문가의 한 복셀 경계 판정과는 다르므로 모든 개인 라벨을 참고용으로 유지한다. 검수된 임상 정답을 꾸며 채점하는 과제는 없다.
- 과제 응답·구조·방향·사례·도움·관찰 깊이·자기 점검과 이전 노출 여부를 기록한다. 전이 재노출을 첫 개인 일반화 평가로 표시하지 않는다.
- 전체 기존 구조·기능 위치·회로는 별도의 참고 Atlas에서 유지한다. 표적 대비가 없는 미세 핵, 기능 회로, 내포 전용 마스크를 직접 식별 정답으로 추가하지 않았다.

전문가 경계 검수와 교육 효과 검증은 여전히 별도의 후속 검증이다. 현재 완료 범위는 위 목표의 **훈련 경험과 그 재현 가능한 데이터·소프트웨어**이며, 임상적 정확도가 인증된 자동 채점기나 진단 도구의 완성을 주장하지 않는다.
