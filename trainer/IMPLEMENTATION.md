# 개인 MRI 판독 훈련 구현·검증 경계

2026-09-06. 기준: REDESIGN.md (PLAN.md의 atlas 이력보다 우선).

## 디자인 맥락
정신과 전문의가 개인 MRI의 연속 단면에서 형태·경계·주변 관계를 읽는 훈련용 앱. 기존 조용한 아이보리·세이지, MRI 중심 분할, 구조 목록·우측 설명 패널, 3D 조작을 유지한다. 새 장식이나 전면 재설계보다 영상·학습 경험의 품질을 높인다.

## 구현 순서
- [x] StudyForrest 4명 원본 T1/T2 확보, checksum·헤더·방향·강도 기록. 원본 보존.
- [x] T1 기준 T2 강체 정합, 변환·단일 resampling 기록 및 시각 QC.
- [x] 개인 segmentation의 native 공간 확인, 영역별 랜드마크·불확실성·검수 계약. 전문가 검수가 없는 경계를 채점하지 않는다.
- [x] 기존 분할 내부에 개인 사례 뷰어 도입, 기본 화면으로 연결. 라벨 없이 관찰, T1/T2·단일/3면·연속 스크롤·window/level·확대.
- [x] 안내 학습, 출현–변화–소실 추적, 동일인 시퀀스/다른 개인 비교, 별도 개인 전이 과제와 서술·도움 사용 기록.
- [x] 초기 핵심 구조·랜드마크와 전체 기존 구조/회로 참고를 연결. 개인 공간에 MNI 마스크·커서를 겹치지 않는다.
- [x] 검수 전 위치 응답은 정오 점수 없이 참고 피드백. 사례 노출과 평가 분리 기록; 첫 응답 보존; 구조·방향·도움·사례별 복습/내보내기.
- [x] 실데이터 QA·브라우저 end-to-end·모바일·오류 및 로딩 경합·기존 atlas/3D 회귀 검증.
- [x] README·출처·완료/제약 근거 정리. Git 초기화와 요청 remote 연결. 최종 커밋·push 결과는 Git 이력과 완료 응답에 기록한다.

## 정답 기준
자동 segmentation이나 atlas 소속은 임상 정답이 아니다. 소프트웨어 검증과 영상상 위치 검토는 전문가 경계 검수와 별도 기록한다. 검수되지 않은 영역은 관찰·서술 및 참고 비교만 활성화한다. 작은 핵/기능 회로는 실제 대비에서 검증될 때까지 직접 식별 채점 대상이 아니다.
