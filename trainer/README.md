# MRI Tutor — 개인 MRI를 읽는 연습

정신과 전문의가 개인 MRI의 위치·형태·주변 관계를 연속 단면에서 설명하도록 돕는 로컬 웹앱입니다. 첫 화면은 해부학 Atlas입니다. 상위 메뉴는 **해부학 Atlas → Atlas 위치 연습 → 실제 MRI** 순서입니다. Atlas에서 구조와 위치를 익히고 단면 위치 연습을 거친 뒤, 실제 MRI에서 StudyForrest 참여자의 T1/T2 촬영 영상을 관찰합니다. 3D 구조 찾기는 Atlas 위치 연습의 보조 연습으로 제공합니다. 기존 3D 조작과 너비 조절 분할도 유지합니다.

구조 위치의 출처, 탐색 십자선의 의미, 개인 MRI의 AAL normalization 수행 여부는 [위치 근거와 검증 범위](ANATOMICAL_VALIDITY.md)에 정리했습니다.

## 실행

프로젝트 루트에서 다음을 실행하면 서버를 시작하고 기본 브라우저로 앱을 엽니다.

```sh
./start.sh
```

브라우저를 자동으로 열지 않으려면 `./start.sh --no-browser`, 포트를 지정하려면 `./start.sh --port 8092`를 사용합니다. 스크립트의 절대 경로를 사용하면 다른 폴더에서도 실행할 수 있습니다. macOS에서는 `trainer/Start MRI Tutor.command`로도 실행할 수 있습니다.

서버는 기본적으로 `0.0.0.0:8091`에서 모든 IPv4 네트워크 인터페이스의 연결을 받습니다. 같은 네트워크의 다른 기기에서는 `http://<서버 컴퓨터의 IP>:8091/`로 접속합니다. 공유기 밖 인터넷에서 접속하려면 별도로 포트 포워딩 또는 VPN과 방화벽 허용이 필요합니다.

기본 주소는 `http://127.0.0.1:8091/`입니다. 기본 포트는 8091로 고정됩니다. `start.sh`는 해당 포트를 사용 중인 기존 프로세스를 종료한 뒤 같은 포트에서 서버를 시작합니다. 종료 요청 후에도 3초 동안 응답하지 않으면 강제 종료합니다. `--port`를 지정하면 지정한 포트에만 적용됩니다. `serve.py`를 직접 실행할 때는 포트가 사용 중이면 안내 후 종료합니다. 포트 포워딩의 내부 목적지는 서버 컴퓨터의 IP와 TCP 8091로 설정합니다. 같은 주소·브라우저 프로필에서 진도가 유지됩니다. 사용 중 서버를 실행한 터미널을 닫지 마세요. 이미 열린 영상이 보여도 서버가 종료되면 새 영상이나 Atlas는 불러올 수 없습니다. 서버를 다시 실행한 뒤 오류 화면의 `Atlas 다시 불러오기` 또는 개인 영상의 `다시 불러오기`로 복구할 수 있습니다. Python 3와 WebGL2 브라우저가 필요합니다. `serve.py`는 HTTP/1.1 연결 유지와 넉넉한 요청 대기열을 사용합니다. 브라우저를 자동으로 열지 않으려면 `python3 trainer/serve.py --no-browser`로 실행하세요. Chrome에서 검증했으며 Safari의 GPU·메모리 동작은 검증하지 않았습니다. 실행 중 인터넷·API 키·AI 서비스는 사용하지 않습니다.

## 개인 영상 판독 훈련

상단의 **사례 1 · 사례 2 · 사례 3** 버튼으로 사람을 선택하고, 바로 옆의 **T1 · T2** 버튼으로 영상을 바꿉니다. 자유 탐색에서 사례를 바꾸면 선택한 구조와 좌우, T1/T2 선택은 유지하고 새 사례의 해당 구조 위치로 이동합니다. 같은 사례의 T1/T2 전환은 현재 단면 위치를 유지합니다. 다른 사람 사이에서 동일한 좌표나 절편을 강제로 맞추지는 않습니다.

**탐색에서 주변 구조 찾기:** 탐색 화면에는 문제풀이용 판단·근거 입력·확신도·응답 저장 영역이 표시되지 않습니다. MRI에서 궁금한 곳을 클릭하면 같은 단면의 반경 15 mm 안에서 등록된 구조를 찾아 노란 점으로 표시합니다. 각 점에 마우스를 올리거나 터치하면 좌우·구조 이름이 나옵니다. 키보드 Tab으로도 점의 이름을 확인하고 Esc로 닫을 수 있습니다. 다른 곳을 클릭하면 이전 점을 새 결과로 교체합니다. 반경은 10/15/25 mm로 바꿀 수 있고, **점 지우기**로 숨길 수 있습니다. 점은 해당 개인의 참고 라벨 안의 한 지점이며 구조 전체의 중심을 뜻하지 않습니다. 단면·사례·시퀀스를 바꾸면 이전 점은 사라집니다. 3면 동시 보기에서는 클릭한 단면에만 표시합니다.

1. **구조 찾기 연습**: 앱이 기본 해부학 구조 9종에서 구조와 좌우를 무작위로 고르고, 해당 개인의 참고 영역이 충분히 포함된 축상·관상·시상 단면을 차례로 보여줍니다. 영상에서 위치를 클릭한 뒤 **이 위치 확인**을 누르세요. 맞는 위치·경계 근처·다른 위치를 구분해 설명하고, 참고 영역과 내부 지점을 표시합니다. **모르겠어요 · 정답 보기**도 사용할 수 있습니다. **다음 단면에서 찾기**로 세 단면을 연습한 뒤 새 문제로 넘어갑니다. 글 작성은 필요 없으며, 주변 구조를 따라 찾는 설명은 항상 표시합니다.
2. **연속 추적**: 같은 방향에서 서로 다른 깊이에 출현 → 형태 변화 → 소실 지점을 순서대로 기록합니다. 앞뒤 이동은 휠·↑↓·좌표 슬라이더·±1 mm 버튼으로 합니다. 자동 분할의 범위가 실제 조직의 끝을 보증하지는 않습니다.
3. **비교**: 동일인의 원본 T1과 정합 T2는 같은 T1 world 좌표를 공유합니다. 다른 개인은 독립 좌표로 탐색합니다. `각자의 구조 위치로`는 각 개인의 참고 위치로 이동하는 도움입니다. 개인 간 정밀 정합이나 동일한 절편이라는 뜻이 아닙니다.
4. **전이 연습**: 학습에 사용하지 않은 별도 사례 04입니다. 첫 응답 전 참고 힌트·경계·3D는 가리지만 단면과 시퀀스는 이동할 수 있습니다. 이 사례를 한 번 연 뒤의 새 연습은 ‘이전 노출 있음’으로 기록합니다. 첫 노출 세션의 미완성 응답은 새로고침해도 이어집니다.
5. **서술형 응답과 피드백 (추적·비교·전이)**: 위치를 찾음 / 단면에 없음 / 현재 대비에서 식별 어려움을 구분하고 근거를 적습니다. 위치를 찾았다면 MRI에서 클릭해야 합니다. 이후 단면을 이동하면 이전 클릭은 무효가 되어 잘못된 위치가 제출되지 않습니다. 첫 응답은 잠기고 실제 영상·주변 관계·자동 분할과 대조하는 참고 피드백이 나옵니다.
6. **학습 기록**: 사례·구조·방향·도움 사용·서술·추적 지점·자기 점검을 저장합니다. 최근 관찰에서 복습하고 JSON으로 내보낼 수 있습니다. 개인 영상에서는 임상 정답률을 계산하지 않습니다.

MRI 위에서 일반 휠은 단면을 이동하고, **⌘ Command + 휠**은 확대·축소합니다. 휠을 위로 돌리면 확대, 아래로 돌리면 축소하며 범위는 1–4배입니다. 개인 MRI·비교 영상·해부학 Atlas에 동일하게 적용됩니다.

확대, Window/Level, T1/T2, 단일 axial/coronal/sagittal 및 3면 동시 보기를 제공합니다. 파일의 강도 상세는 그대로 두고 화면 표시 범위만 바꿉니다. R/L은 환자 기준, 좌우는 방사선학적 표시입니다. 좌표는 해당 개인의 T1 scanner RAS이며 MNI 좌표가 아닙니다. 헤더에 기초한 좌우를 별도의 물리적 좌우 표지로 검증한 것은 아닙니다.

## 범위와 검수 상태

4명의 T1/T2, 26개 주제와 104개 관찰 과제 계약, 개인별 46개 좌우·정중 참고 구획을 제공합니다. 핵심 주제는 해마, 편도체, 미상핵, 조가비핵, 담창구 전체, 시상, 뇌섬엽, 대상회, 측뇌실, 뇌량, 내포입니다. 내포는 개인 라벨 없이 주변 랜드마크로 관찰합니다. 추가로 측좌핵 영역, 해마곁이랑·내후각피질, 안와전두피질·상전두회·중전두회, 중심앞·뒤이랑, 쐐기앞소엽·하두정 영역, 측두각·제3·4뇌실, 뇌간·소뇌 피질을 탐색할 수 있습니다. 관찰 부위 필터와 구조·랜드마크 검색으로 범위를 좁힐 수 있습니다. 피질 parcel은 기능 영역·치료 표적과 같지 않습니다.

원본 다운로드·checksum·헤더·방향·강도·양측 라벨 앵커 및 세 방향 시각 QC를 수행했습니다. 자동 FreeSurfer 분할의 전문의 경계 검수는 수행하지 않았습니다. `reference-only`, `scoreable:false`로 남기고 임상 정답으로 채점하지 않습니다. ‘단면 범위 안/밖’ 피드백은 자동 라벨의 기하학적 범위 비교이지 가시성·부재의 확정 판정이 아닙니다.

작은 핵과 기능적 영역은 기존 42종 해부학 Atlas에서 탐색합니다. SN·LC 등의 표적 대비 영상은 이번 사례에 없으며 일반 T1/T2에서 작은 핵의 직접 경계 식별을 평가하지 않습니다. 기능 회로나 dlPFC/vmPFC의 경계를 T1에서 직접 보이는 구조로 다루지 않습니다. 질환 사례·FLAIR/DWI/SWI 판독, 해마 사위 재구성, MTA/Fazekas 등 임상 척도, 환자 영상 업로드, 교육 효과 검증은 포함하지 않습니다.

## 3D와 분할

개인 모드의 핵심 3D는 해당 개인의 자동 분할에서 만든 참고 표면입니다. 현재 MRI의 실제 native 단면을 같은 개인 T1 공간에 표시하고, 같은 plane으로 구조를 절단할 수 있습니다. 주제와 필요한 이웃 구조를 중심으로 표시하며 회전·확대·선택 구조만·전체 구조 보기를 제공합니다. 별도 해부학 Atlas에서는 기존 표준 모델과 투명도·반구 절단을 유지합니다. 피질 pial/white 표면과 전문가 경계 검수는 후속 범위입니다.

넓은 화면에서는 왼쪽 3D·오른쪽 MRI를 기본 40:60으로 나란히 표시합니다. 세로 분할선을 좌우로 끌거나 ←/→ 키로 너비를 조절합니다. 양 끝은 각각 MRI만/3D만이며 `3D + MRI`로 복원합니다. 비율은 저장되며 뷰어·카메라·MRI 위치는 유지됩니다. Home(MRI만), End(3D만), Enter(분할 복원), 두 번 클릭(기본 40/60)도 사용할 수 있습니다. 작업 영역이 좁으면 위아래 배치로 전환하며 ↑/↓로 높이를 조절합니다. 해부학 Atlas와 개인 MRI 기본 탐색은 Axial 단일 단면으로 시작합니다. Coronal·Sagittal·3면 동시도 선택할 수 있으며, 구조 찾기 연습의 지정 단면과 저장된 학습 진행은 유지합니다.

`해부학 Atlas`는 표준 공간의 해부학 지도와 집단 평균 T1 템플릿을 이용하는 학습 모드입니다. Atlas의 영상은 **표준 MRI 템플릿**, 참여자별 촬영 영상을 보는 메뉴는 **실제 MRI**로 구별합니다. Atlas 위치 연습·보조 3D 구조 찾기·회로 탐색을 제공합니다. Atlas ROI 포함 여부 점수는 개인 MRI 판독 능력 평가와 별개입니다.

## 재현

선택된 앱 영상·라이브러리가 저장소에 포함됩니다. 원본 staging과 파생 과정을 다시 만들려면 Python용 `uv`, 계약 생성에는 Node 20+를 사용합니다.

```sh
python3 scripts/fetch_individual_cases.py
uv run --with-requirements scripts/individual-requirements.txt python scripts/build_individual_cases.py
node scripts/build_case_contracts.mjs
uv run --with-requirements scripts/individual-requirements.txt python scripts/validate_individual_cases.py
```

다운로드는 git-annex의 크기·MD5/SHA256을 검증하고 SHA-256 기록을 추가합니다. T1과 원본 T2는 그대로 보존합니다. T2는 SimpleITK Euler3D 강체 정합 후 원본으로부터 선형 보간 1회로 T1 격자에 float32 저장합니다. 동일 촬영의 FreeSurfer rawavg와 T1을 복셀 순서로 대조하여 헤더 차이를 보정하고, 개인 분할 자체는 native 1 mm 격자에 보존합니다. 좌표·변환·checksum·검수 범위는 `assets/cases/*/case.json`에 있습니다.

기존 시각 QC는 검사한 파일 해시와 연결되어 있으며 파생 데이터가 바뀌면 계약 생성이 실패하여 재검토를 요구합니다. 재검토가 필요할 때 `qc-review.json`의 승인 상태를 임의로 올리지 마세요.

```sh
uv run --with-requirements scripts/individual-requirements.txt python scripts/review_individual_cases.py
uv run --with-requirements scripts/individual-requirements.txt python scripts/review_individual_cases.py --right
npm ci
npm test
npm run test:browser
npm run test:resilience
npm run test:atlas-recovery
npm run test:expanded
```

브라우저 테스트는 별도 임시 Chrome 프로필을 쓰며 실제 사용자 진도를 변경하지 않습니다. 로컬 서버를 먼저 실행해야 합니다. 테스트 코드는 운영 중 인터넷이 필요한 것이 아니며 개발용 Playwright만 사용합니다.

## 개인 MRI와 같은 사람의 3D (2026-09-09)

개인 모드에서 **탐색 → 3D + MRI**를 열면 현재 사례의 자동 분할로 만든 18개 핵심 구획과 실제 MRI 단면을 볼 수 있습니다. 구조 찾기 연습은 첫 응답 뒤 **같은 단면을 개인 3D로 보기**를 사용합니다. `MRI 절단면`, `단면으로 절단`, `선택 구조만`, `전체 구조`를 조절할 수 있습니다. 3D 클릭은 원래 mask 내부의 가까운 지점으로 이동합니다.

개인 피질 표면 전체는 아직 포함하지 않습니다. 개인 팩이 없는 구조는 그 사실을 표시하고 표준 모델로 바꾸지 않습니다. 자동 분할은 전문 경계 검수 전 참고용이며 임상 정답이 아닙니다.

재현·팩 버전·rollback flag·측정 결과는 [구현 기록](../docs/ATLAS-INTEGRATION-IMPLEMENTATION.md)에 있습니다. 새 생성물은 `assets/packs/subject-core/`에만 추가하며 원본 MRI와 label을 보존합니다. 기존 팩을 다시 만들려면 새 버전으로 `npm run build:subject -- --version 2`를 실행합니다.


## 설명 속 해부학 용어와 위치 표시

오른쪽 설명은 한글 해부학 용어 뒤에 영어를 괄호로 병기합니다. 밑줄 친 용어를 누르면 설명 주제는 유지한 채 현재 MRI의 같은 쪽 구조에 노란 원을 표시합니다. 현재 단면에 해당 구획이 없으면 등록된 대표 위치의 단면으로 이동합니다. 단면을 바꾸어 표시 위치가 보이지 않으면 원도 숨겨집니다. 위치 연습의 답 확인 전에는 이 링크가 잠깁니다. 사용자가 작성한 관찰 기록은 자동으로 고치지 않습니다.

위치는 현재 영상에 등록된 마스크로 확인합니다. 최외포·외포의 개별 마스크는 아직 없고, 담장은 별도 Allen/ICBM2009b MRI에서만 표시할 수 있습니다. 현재 MRI에 위치가 등록된 구조에만 링크를 제공하며, 나머지는 한글·영어를 병기한 일반 텍스트로 표시합니다.

영상에서 미등록 위치를 직접 클릭하면 이전 선택 이름·설명·강조 표시가 사라지고 **미등록 위치**가 나타납니다. 연속 단면을 스크롤할 때는 학습 중인 구조 설명을 유지합니다.

검증: `npm test`, `node tests/anatomy-browser.mjs`, `npm run test:browser`.

## 축상면·관상면 참고 도식

오른쪽 해부 도식에는 사용자가 제공한 `Telencephalon.pdf`의 축상면 10장과 관상면 10장을 표시한다. 현재 MRI 단면에 가까운 그림을 자동 선택하며, 이전·다음으로 직접 고른 뒤 ‘현재 MRI 단면 따라가기’로 돌아올 수 있다. 그림을 누르면 중앙 확대 창에서 최대 4배 확대, 드래그·스크롤, 이전·다음 및 좌우 방향키를 사용할 수 있다. Escape로 닫는다. 3면 보기에서는 참고 도식의 방향을 따로 고르며 시상면 전용 그림은 없다. 비교 모드는 왼쪽 주 영상에 대응한다.

단면 대응은 정합이 아닌 근사 선택이다. 표준 공간에서는 작성한 대표 높이를 사용하고, 개인 MRI에서는 양측 시상 anchor의 중간 위치로 평행이동만 보정한다. 회전·크기 보정은 수행하지 않는다. 기준이 없으면 수동 탐색으로 표시하며 도식 범위 밖은 가장 가까운 끝 단면임을 알린다. 선택은 MRI 좌표·라벨·판정을 바꾸지 않는다.

자유 탐색에서는 자동 표시한다. 안내·추적·비교 연습의 답 확인 전에는 ‘도식 힌트 보기’로 열고 도움 사용을 기록한다. Atlas 위치 연습과 별도 개인 전이 연습에서는 첫 응답 전 이름이 표시된 도식을 잠근다.

원본 PDF는 보존한다. `assets/illustrations/telencephalon/manifest.json`에 원본 SHA-256, 그림 번호, 책/PDF 쪽수, crop 영역과 큰 이미지 해시를 기록한다. 본문은 제외하고 그림·구조명·연결선·단면 위치 안내·작가 표기를 함께 렌더링했다. 작은 미리보기와 큰 이미지를 분리해 전체 20장을 한꺼번에 내려받지 않는다.

재생성: `uv run --with pymupdf --with pillow python scripts/build_reference_illustrations.py` (프로젝트 루트의 원본 PDF 필요). 검증: `npm test`, `node tests/illustrations-browser.mjs`.
