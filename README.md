# MRI Tutor

정신과 전문의를 위한 개인 Brain MRI 해부학 판독 훈련 앱입니다. 실제 StudyForrest 개인 4명의 T1/T2 영상에서 라벨 없이 위치·연속성·주변 관계를 관찰하고 설명합니다. 기존 아이보리·세이지 디자인과 3D 공간 참고 모델을 유지합니다.

```sh
python3 trainer/serve.py
```

또는 macOS에서 `trainer/Start MRI Tutor.command`를 실행합니다. 기본 주소는 `http://127.0.0.1:8091/`입니다. WebGL2 지원 브라우저가 필요합니다. Chrome에서 검증했습니다. 런타임은 정적 HTML/JS와 포함된 영상으로 동작하며 인터넷·API 키·Node 설치가 필요하지 않습니다.

서버는 기본적으로 `0.0.0.0:8091`에서 모든 IPv4 네트워크 인터페이스의 연결을 받습니다. 같은 네트워크의 다른 기기에서는 `http://<서버 컴퓨터의 IP>:8091/`로 접속합니다. 공유기 밖 인터넷에서 접속하려면 별도로 포트 포워딩 또는 VPN과 방화벽 허용이 필요합니다.

학습용 3명과 별도 전이 연습용 1명을 구분합니다. 자동 개인 분할은 **참고 자료**이며 전문가 검수된 임상 정답이 아닙니다. 첫 응답·도움·추적·자기 점검을 기록하며 개인 MRI에서 정답률이나 진단 점수를 만들지 않습니다. 임상 진단이나 교육 효과가 검증된 제품은 아닙니다.

대용량 영상이 포함되어 clone 시 약 400 MB의 데이터가 필요합니다. Git LFS나 외부 API는 필요하지 않습니다. `trainer/assets/cases/source/`의 원본 다운로드 staging은 추적하지 않으며 해시 검증 다운로드 스크립트로 복원할 수 있습니다. 기존 교과서 PDF·추출 결과·이전 `demo/`는 로컬에 보존하며 공개 저장소에 포함하지 않습니다.

데이터마다 라이선스가 다릅니다. StudyForrest는 PDDL이고, 기존 atlas에는 비상업·동일조건변경허락 자료도 포함되어 있습니다. 전체 저장소를 단일 라이선스의 무제한 상업용 데이터로 해석하지 마세요.
