# 해부 삽화 분리 가능성 검토

2026-09-10. 범위: 구현에 앞선 원본 조사와 첨부 예시의 추출 실험.

## 결론

가능하다. `Telencephalon.pdf`의 그림 13.6A(PDF 12쪽, 책 310쪽)를 실제로 분리했고, 라벨 포함 버전과 순수 삽화 버전을 각각 확인했다. 원본 PDF와 앱에서 사용하는 자산 및 코드는 변경하지 않았다.

- **라벨 포함:** 큰 삽화와 모든 해부학 라벨을 포함하는 사각형으로 범위를 좁힌 뒤, 함께 들어오는 좌측 보조 그림과 MRI 영역 두 곳만 PDF 위에서 흰색으로 가렸다. 그림의 복잡한 윤곽을 따라 자를 필요가 없다. 원래 작가 표기를 유지했다.
- **순수 삽화:** PDF 내부 비트맵에는 라벨과 연결선이 없다. 이들은 별도의 PDF 텍스트·벡터 객체다. 비트맵을 PDF 이미지 객체로 배치하고 큰 삽화 영역만 렌더링하면 원본 그대로 얻을 수 있다. 원본 작가 표기는 하단에 별도로 옮겼다.
- 라벨 유지 샘플은 제외 영역 밖의 RGB 픽셀이 기존 PDF 렌더링과 일치한다. 마스크 경계 주변 1 PDF point는 비교에서 제외했다. 생성형 이미지 수정이나 지워진 부위 복원은 사용하지 않았다.

## 전체 적용 방향

축상면 10장·관상면 10장을 조사한 결과 각 페이지는 비트맵 1개와 별도 텍스트·벡터 객체로 구성된다. 기존 20장 contact sheet에서도 좌측 보조 그림과 우측 주 삽화가 분리된 배치를 확인했다. 다만 이번에 완성·검증한 추출물은 axial-06 한 장이다. 나머지 19장은 라벨별 분리 상태 및 경계 검수가 필요하다.

권장 UI는 라벨을 포함한 주 삽화를 기본으로 보여주고, 원본 전체 보기와 라벨 없는 보기를 선택 가능하게 하는 것이다. 전체 적용 시 그림별 좌표를 선언적으로 저장하고 기존 builder가 파생 자산을 생성하도록 확장한다. 자동 윤곽 인식에 의존하기보다 20장 각각의 범위와 제외 영역을 지정하고 연락선·글자·작가 표기의 잘림을 검수하는 편이 예측 가능하다.

축상면 6번의 기존 영역은 564 × 672 PDF points, 라벨 포함 추출 영역은 399 × 510 points다. 같은 표시 폭에서는 약 1.41배 크게 보인다. 높이에 제한된 화면에서는 확대 이득이 달라진다. 라벨을 남기는 한 라벨 주변 여백 일부도 필요하다.

원본 주 삽화 영역 자체는 약 582 × 723 픽셀이다. 고해상도로 렌더링해도 삽화의 새 세부 묘사가 생기지는 않는다. PDF의 별도 글자와 선은 상대적으로 선명하게 렌더링할 수 있다.
